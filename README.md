# IT340-Project-DailySpark
DailySpark is a community-driven daily content website (a daily digest with user comments and user-suggested
content). It is a full-stack web application deployed in a local IaaS environment of VM's.

Daily Spark gives people a single place to find fresh, interesting content each day without searching several sites.
Every day the site automatically publishes a set of curated sections, and registered members can discuss each one in
a comment thread. Members can also suggest questions for the community, which turns a passive reading site into a
conversation.
